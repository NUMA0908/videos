# Juegos

Sección del repositorio **separada del estudio de videos**. Aquí van juegos web independientes:
no usan Remotion, no dependen de `src/` ni de `npm install`, y no les aplican las reglas de
marcas/anuncios de `CLAUDE.md`.

| Juego | Carpeta | Cómo jugar |
| --- | --- | --- |
| La Llorona (terror) | [`la-llorona/`](la-llorona/) | Abre `la-llorona/index.html` en el navegador |

Antes de empezar un juego nuevo, lee [`GUIA-JUEGO-DE-TERROR.md`](GUIA-JUEGO-DE-TERROR.md): todo lo aprendido
con La Llorona (diseño de terror, mecánicas con sus números, IA, visuales, audio, técnica y
pruebas), escrito para reutilizarse con otras criaturas e historias.
